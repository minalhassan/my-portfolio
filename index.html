CPU Scheduling Simulator

Developed a Java-based simulator for visualizing and analyzing CPU scheduling algorithms, a core concept in operating systems. The project supports multiple scheduling techniques such as First-Come, First-Served (FCFS), Shortest Job Next (SJN), and Round Robin (RR), enabling users to compare performance metrics like waiting time, turnaround time, and CPU utilisation. Featuring a graphical user interface (GUI), the simulator provides an interactive environment to test algorithms with custom process inputs.

Key Responsibilities:

  • Designed and implemented core scheduling algorithms (FCFS, SJN, RR, etc.) in Java
  • Built a graphical user interface (GUI) for user-friendly interaction and visualisation of process execution
  • Developed custom data structures to efficiently manage processes and scheduling queues
  • Implemented features for detailed performance analysis, including waiting time, turnaround time, and CPU utilisation
  • Configured project structure with Maven for dependency management and build automation
  • Conducted testing of different scheduling scenarios to validate algorithm accuracy and performance
